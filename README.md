## Stock Monitor

Utility for financial data monitoring written in Scala 3

**(Work in progress)**

---

## Purpose

The goal of this project is a Scala application gathering live stock data and other financial data
along with auxiliary data (e.g. currencies exchange rates) and present it to the user so that they
can be explored and drilled-down.


## Features implemented up to this point

- utility for live currency conversion using [exchangerate-api.com](https://www.exchangerate-api.com) API
- API client for [TwelveData](https://twelvedata.com/docs)
- data manipulation utilities


## Data sources

### Currency exchange data

<a href="https://www.exchangerate-api.com">Rates By Exchange Rate API</a>

### Exchanges and stocks data
